How to play

  • Adjacent tiles (upar-neeche / left-right) ko swap karo.
  • 3 ya zyada same icon ek line me aaye to they crush & score milega.
  • Har level ka ek score target aur moves limit
  • Target score se upar pahuchte hi next level unlock ho jayega.

Gensyn Swarm Characters

  • 🐝 Bee – Fast workers in the swarm.
  • 🐻 Bear – Heavy compute power.
  • 🐜 Ant – Tiny but many, like nodes.
  • 💻 Code – Code Assist energy.
  • 🧱 Block – Block Assist support.

Tip: Smart swaps karo takki ek move se multiple matches ho – true wisdom of the swarm 😉
